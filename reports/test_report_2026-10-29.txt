Unresolved issues
=================
A. Previously identified: PySCF may falsely report geometry convergence.
   src/qchem_interfaces/pyscf_run.rs:187 calls geometric_solver.optimize,
   which returns geometry without the optimizer's convergence flag. The
   wrapper at src/qchem_panel/run.rs:788 marks trajectory-producing jobs
   as converged when they return. A later successful SCF calculation does
   not prove geometry optimization convergence. This was established from
   installed source/API behavior; no real unconverged optimization was run
   because geometric is missing. No fix was authorized or made here.

B. Newly reproduced: constrained conformer search can falsely report Rigid.
   The explicitly run ignored test
   conformer::tests::a_constrained_search_holds_its_coordinates FAILED
   immediately at src/conformer/mod.rs:1366 with:
       a constrained butane is searchable: Rigid
   src/optimizer/conformer_search/topology.rs:46-51 treats a fixed bond
   length as holding its torsion; lines 257-260 exclude that degree of
   freedom. Butane's remaining methyl rotations are excluded separately.
   An independent rotation of the test's carbon geometry changed its
   dihedral by 60 degrees while changing both constrained bond lengths
   by exactly zero. The fixed lengths do not make this molecule rigid.
   This supports a functional error rather than merely a stale expectation.
   No fix was made.

C. Newly reproduced: ORCA output routed to the TD-DFT reader from credits.
   examples/TS_Gamma-3-6_ZZ-S_11.out is a normally terminated ORCA output
   without the excited-state table that the reader requires. Mentions of
   TD-DFT in its contributor credits match the broad marker search in
   src/cli.rs:126-140. Opening it reports "no TD-DFT excited states found"
   instead of explaining that ORCA force constants need the companion
   .hess file. The companion Hessian loaded successfully in a separate run.
   This is a routing/diagnostic problem, not a crash or corrupted result.
   No fix was made.

D. Environment limitation: geometric is absent from the selected PySCF venv.
   That blocks PySCF geometry optimization. It is separate from issue A.
   No package was installed. Behemoth and other unconfigured backends also
   remain unvalidated. macOS and Windows were not tested.

Requested Surface Tools change
==============================
Only the specifically requested runtime UI behavior was changed:
   src/orbitals/ui.rs reserves the floating window's chosen height and
   lets its orbital list use the available vertical space rather than
   stopping at 180 pixels. Docked layout retains its previous list height.
   No shared window behavior or chemistry implementation was changed.
   src/orbitals/ui_resize_tests.rs contains the interactive regression test;
   its declaration is in ui.rs. No implementation was added to mod.rs.

Before the fix, a 140-pixel vertical pointer drag left the real window's
height unchanged. After the fix, the same test passed for growing and
shrinking vertically while keeping width unchanged.
Final normal suite: 1,374 passed. Development build: PASS, 10.97 seconds;

after this change. Its earlier GUI runs therefore validate the pre-change
