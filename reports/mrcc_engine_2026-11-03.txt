MRCC engine integration — 2026-11-03
==================================

Scope
-----
Added MRCC to the Quantum Chemistry panel for energies and excited states,
then added Beavyr-driven minimum optimization where a supported analytical
MRCC gradient is available, as requested. No Hessian, TS, scan or MECP support
is claimed for this integration. No commits or pushes were made.

The executable is selected by the user in Configure and remembered in
mrcc_path.txt. There is no installation-specific executable path in the
application. The local installation used for validation was
/home/peter/Programs/MRCC/binary/dmrcc, which reports version 26.1.3.

Methods and jobs
----------------
Ground-state energies:
  HF, DFT, MP2, RI-MP2, MP2-F12, CCSD, CCSD(T), UCCSD(T), CCSD-F12,
  CCSD(T)-F12, CCSDT, CCSDT(Q), CCSDTQ, CASSCF, NEVPT2 and dRPA.

UCCSD(T) means CCSD(T) with an unrestricted HF reference, not unitary CC.
Other compatible methods automatically use UHF for multiplicity > 1, and
have an unrestricted-reference setting. CASSCF uses MCSCF instead.
NEVPT2 reports the strongly contracted energy; the PC-NEVPT2 energy is
retained in the native output but is not silently substituted.
MRCC's CCSD-F12 and CCSD(T)-F12 labels use its CCSD(F12*) and
CCSD(F12*)(T) energies, respectively. Scaled triples energies printed by
MRCC remain in the native output.

Excited states:
  HF: CIS (TDA enabled) or TDHF.
  DFT: TDA or full TDDFT.
  ADC(2), SCS-ADC(2), SOS-ADC(2).

The excited-state interface currently requires a restricted closed-shell
singlet. The requested count refers to excited states; MINP's nstate also
includes the ground state, so it receives requested_count + 1. Final ADC
roots replace preliminary CIS/TDHF roots. The parser reads final length-
gauge oscillator strengths and transition dipoles; it never substitutes
preliminary strengths when the final correlated table is absent.

Analytical gradients and Beavyr optimization:
  HF; PBE, PBE0, BLYP, B3LYP, BP86, TPSS, TPSSh, M06 and M06-2X DFT;
  closed-shell RHF RI-MP2; CCSD; CCSDT; CCSDTQ.

Conventional MP2 is offered as energy; choose RI-MP2 for its supported
analytical gradient. Perturbative CCSD(T), CCSDT(Q), F12, CASSCF/NEVPT2,
dRPA and ADC optimization are not offered. No numerical-gradient fallback
is performed. The existing Beavyr optimizer provides the coordinate choices,
convergence tolerances, iteration limits, trajectory and convergence status.
MRCC's gradient in ORIGINAL ORIENTATION is required and read in Hartree/bohr.

Core correlation and inputs
---------------------------
Frozen core is the default. Correlate core electrons writes core=corr and
requires a recognized cc-pCVXZ or cc-pwCVXZ orbital basis, including augmented
variants. Valence-only bases are rejected when core correlation is selected.
For H/He, an explicit atomtype basis block selects the corresponding valence
member, since these atoms have no core shell. Other atoms retain the selected
core-correlation basis.

Core-correlated F12 is not enabled in this interface. Core-fitting F12
auxiliary basis sets in the installation are not core-correlation orbital
bases; they must not be used as such.

CASSCF and NEVPT2 use the existing active-electron/orbital controls. Electron
count, active-space parity, charge/multiplicity and atom coordinates are
validated. Dummy atoms are removed before generating the input.

MINP is generated with explicit charge, multiplicity, basis, reference,
resources, units and C1 symmetry. The input editor permits selected extra
SCF/CC convergence controls, but scientific settings/geometry must remain
consistent with the panel and cannot bypass its validation.

Execution and results
---------------------
Each job writes MINP in its own scratch directory and launches the chosen
dmrcc directly, without an input filename argument or a shell. The executable's
parent is prepended to PATH ONLY in its child process so MRCC can find its
companion programs. OMP_NUM_THREADS and MKL_NUM_THREADS follow the selected
core count. No shell startup files, global environment or ORCA MPI settings
are modified.

Cancellation terminates the MRCC process group, including companion programs.
Live Output discovers mrcc.out/mrcc.err. Input, native output and analytical
gradients are available to save; the existing complete-calculation export
retains the run directory and metadata. Abnormal termination, non-convergence,
missing requested-level energies and incomplete/non-finite gradients are
errors. A missing correlated energy is never replaced with an HF/MP2 value.

Write Orbitals saves MRCC's MOLDEN file. MRCC rotates/translates geometry to
standard orientation. Automatic Surface Tools loading still requires a
matching displayed geometry; otherwise the existing mismatch message is
shown and the saved file can be loaded separately. No MO rotation or change
to the user's displayed geometry was introduced. A general GUI smoke test
with interactive display/copy/save clicks was not performed in this task.
