1. Constrained conformer search
==============================
The fix examines the actual rotating branch and stationary branch of each
torsion. Atoms on the rotation axis are unchanged. A constraint entirely on
one side, including its axis atoms, survives that rigid rotation.

Consequently, fixing the axis bond's length or an adjacent bond angle does
not remove the torsion. Constraints involving off-axis atoms on both sides
still exclude the conflicting rotation. This includes fixed dihedrals and
cross-branch distances/angles; simply permitting every bond constraint would
have been incorrect. Automatic rotations, explicit rotations, and explicit
cis/trans sampling receive the same check. Existing conservative ring-pucker
constraint handling was preserved.

The public central-bond helper now distinguishes a directly fixed dihedral
from bond lengths and angles; full branch classification stays in the actual
search topology implementation.

Verification:
- New tests rotate a chain in both directions while checking that held bond
  lengths and both adjacent angles remain unchanged.
- Cross-branch bond/angle and forward/reversed dihedral constraints prevent
  conflicting automatic, explicit, and cis/trans rotations.
- The previously failing ignored constrained butane search now passes:
  two conformers in 11.53 seconds; the existing held-coordinate check passes.

2. ORCA output detection

3. PySCF geometry convergence
============================
The generated script now calls geometric_solver.kernel, which returns the
optimizer's actual convergence flag and geometry. It reports that flag
independently of the later SCF calculation. The calculation wrapper parses
the flag instead of unconditionally assigning true to optimization jobs.

Unconverged geometry and trajectory remain available for inspection, with
the existing summary warning that the result did not converge. The final XYZ
comment also marks the geometry as unconverged. A missing or malformed
geometry-convergence status causes an explicit error and cannot be silently
promoted to convergence. Energy-only jobs require no geometry status.
An externally supplied custom optimization script must emit the explicit
BEAVYR_GEOMETRY_CONVERGED 0/1 record to satisfy this runner contract.

Verification:
- Marker parsing checks true, false, missing, malformed, and repeated status.
- An isolated subprocess test exercises the real runner/configuration path
  with controlled executable output, confirming that successful SCF does not
  override false/missing/malformed geometry status. It covers optimization,
  optimization plus frequencies, and an energy-only job.
- Focused PySCF checks: 16 passed, one existing native test ignored in that
  focused invocation; the native test was then run explicitly and passed.
- Real generated PySCF optimization plus frequencies: PASS.
- New real PySCF/geomeTRIC regression through Beavyr's runner: PASS.
  One-step iteration-limited optimization: converged=false,
  energy -74.965718020085 Hartree.
